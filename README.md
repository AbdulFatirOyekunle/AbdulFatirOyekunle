## Featured Project

### Employee Management API
[![Repo](https://img.shields.io/badge/Repository-Open-111111?style=flat-square&logo=github&logoColor=white)](https://github.com/Masterman234/EmployeeManagement)
[![Stack](https://img.shields.io/badge/Stack-ASP.NET%20Core%20%7C%20EF%20Core%20%7C%20SQL%20Server-2563EB?style=flat-square)](https://github.com/Masterman234/EmployeeManagement)

A RESTful Web API for managing employees, companies, and employee education records, built with ASP.NET Core and EF Core.

**Highlights**
- custom token-based authentication scheme with a dedicated `AuthenticationHandler`, secure password hashing (HMACSHA512), and constant-time comparison to prevent timing attacks
- FluentValidation-based request validation across all input DTOs, replacing DataAnnotations for more flexible, testable rules
- paginated list endpoints with a reusable `PagedResponse<T>` wrapper (current page, page size, total count, total pages)
- one-to-many data modeling with EF Core (an employee's multiple education qualifications), including a real migration that safely split a single free-text column into a normalized related table without losing existing data
- Swagger/OpenAPI documentation configured with bearer-token authorization for testing protected endpoints
- structured error handling distinguishing `404 Not Found` from `400 Bad Request` based on failure type
